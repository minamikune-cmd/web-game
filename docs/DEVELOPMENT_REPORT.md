## 1. 项目概况

网页端休闲台球游戏：玩家 VS 电脑 AI，美式 8 球（8-Ball Pool）规则，PC 浏览器 + 移动端兼容，纯静态站点（无构建步骤），目标部署平台 Vercel。

## 2. 架构（模块化，各层独立）

| 模块 | 文件 | 职责 |
|---|---|---|
| 物理 | `js/physics.js` | 常量（TABLE 1000×500、BALL_R 12、6 袋）、球体碰撞/库边反弹/摩擦阻尼/进袋判定、事件追踪（按物理步分组，支持"首碰后碰库"犯规判定）、袋口缓冲带（nearMouth，避免对角线球被库边弹出） |
| 规则 | `js/rules.js` | 摆球（8 号居中、底角一全一花）、开球、分组分配、轮流击球、犯规判定（空杆/白球落袋/首碰错误/无落袋未碰库）、手中球、黑 8 全部胜负分支 |
| AI | `js/ai.js` | 假想球（ghost ball）线路评估、袋口评分、三档难度（easy/normal/hard，瞄准/力度噪声递减）、"选次优解"概率、**出杆前仿真验证（previewFoul，剔除必犯规线路）**、安全球 fallback、LCG 可复现随机 |
| 音频 | `js/audio.js` | WebAudio 合成音效（hit/rail/ball/pocket/place/ui/win/lose），可开关 |
| 渲染 | `js/renderer.js` | 球桌/球（号码、花色条纹）/瞄准线与球杆绘制 |
| UI | `js/ui.js` | 记分板（球组徽章、剩余球、黑 8 目标标记）、主菜单、力度条、胜负结算层、音效开关 |
| 游戏主控 | `js/game.js` | 状态机（menu→placing→aiming→moving→aiThink/aiAim→over）、拖拽瞄准出杆、结算循环、AI 摆球、触屏事件、HiDPI 适配 |

所有模块用 UMD 风格沙盒包装（`(function(global){...})(typeof window!=='undefined'?window:globalThis)`），浏览器直接 `<script>` 引入，Node 可直接 `require` 跑测试。

## 3. 完成情况（对照需求阶段）

1. **基础游戏** ✅ 绘制、瞄准、力度控制、碰撞/反弹、库边、摩擦阻尼、停止判定、游戏循环
